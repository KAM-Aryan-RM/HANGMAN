# HANGMAN
HANGMAN GAME
You are assign a random word. You have to guess the word letter by letter. 

Features:
You will get the hint of the word.
If you guess the letter wrong a body part of man will appear.
Prevents numbers and repeated inputs.
Allows a maximum of 6 wrong guesses.
Displays the hangman using ASCII art.

Prerequisites:
Make sure Python 3 is installed on your system.

Run the Game:
Step 1: Clone this repository.
git clone <https://github.com/KAM-Aryan-RM/HANGMAN>
Step 2: Navigate to the project directory
cd <code>
Step 3: Run the Python file.
python code.py
